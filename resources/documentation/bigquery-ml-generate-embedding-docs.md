# BigQuery ML Generate Embedding Documentation

## Description
Learn how to use BigQuery ML to generate vector embeddings from text data using pre-trained models. The ML.GENERATE_EMBEDDING function allows you to convert text into numerical vector representations that capture semantic meaning, enabling semantic search and similarity matching.
