# Database Migration Service Documentation

## Description
Database Migration Service (DMS) is a fully managed, serverless migration service that helps you migrate your databases to Google Cloud with minimal downtime. It supports homogeneous migrations (same database engine) and heterogeneous migrations (different database engines).

## URL
https://cloud.google.com/database-migration/docs

## Category
documentation

## Target Audience
- Database administrators
- Cloud architects
- DevOps engineers
- IT professionals planning database migrations

## Prerequisites
- Google Cloud Platform account
- Basic knowledge of database administration
- Understanding of source and target database engines
- Familiarity with GCP networking concepts

## Related Labs
- GSP918: Create and Manage Cloud SQL for PostgreSQL Instances

## Notes
Database Migration Service supports:
- Continuous migration with change data capture (CDC)
- Schema conversion for heterogeneous migrations
- VPC peering and private connectivity
- Migration of multiple databases in a single job
- Integration with Cloud SQL, AlloyDB, and Spanner
