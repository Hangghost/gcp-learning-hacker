# BigQuery Vector Search Introduction Documentation

## Description
Learn about BigQuery's vector search capabilities, which allow you to perform similarity searches on vector embeddings stored in BigQuery tables. Vector search enables finding semantically similar items based on their vector representations, which is essential for implementing RAG (Retrieval Augmented Generation) applications.

- Basic knowledge of SQL

## Notes
BigQuery vector search provides efficient similarity search capabilities directly in SQL, enabling powerful AI applications without needing specialized vector databases.
