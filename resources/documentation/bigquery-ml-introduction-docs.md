# BigQuery Machine Learning Introduction Documentation

## Description
Learn about BigQuery Machine Learning (BQML), a feature that lets you create and run machine learning models using SQL queries directly in BigQuery. BQML supports a wide range of ML use cases including classification, regression, recommendation systems, and more.

## URL
https://cloud.google.com/bigquery/docs/bqml-introduction

## Category
documentation

## Target Audience
- Data Scientists
- Data Analysts
- ML Engineers
- Developers working with BigQuery
- Anyone interested in SQL-based machine learning

## Prerequisites
- Google Cloud account with BigQuery access
- Basic knowledge of SQL
- Understanding of machine learning concepts
- Familiarity with BigQuery interface

## Notes
BQML enables you to perform machine learning tasks without moving data out of BigQuery, providing seamless integration with your existing data workflows and reducing complexity.
