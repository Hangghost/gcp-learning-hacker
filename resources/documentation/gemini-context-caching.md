# Gemini Context Caching

## Description
Documentation on context caching in Vertex AI, allowing storage of frequently used input tokens in dedicated caches for subsequent requests.

## URL
https://cloud.google.com/vertex-ai/generative-ai/docs/context-cache/context-cache-overview

## Category
documentation

- Performance engineers
- Cost optimizers
- AI application developers

## Prerequisites
- Vertex AI API access
- Understanding of token caching concepts
- GCP project with Vertex AI enabled

## Notes
Reduces costs and latency by caching frequently used context tokens instead of sending them with every request.
