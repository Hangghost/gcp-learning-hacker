# Dataflow Templates Documentation

## Description
Official documentation for Google Cloud Dataflow templates, including provided templates for common data processing patterns like Pub/Sub to BigQuery, Text Files on Cloud Storage to BigQuery, and more.

## URL
https://cloud.google.com/dataflow/docs/templates/provided-templates

## Category
documentation

## Target Audience
- Data engineers
- Developers working with streaming data
- GCP users implementing ETL pipelines

## Prerequisites
- Basic understanding of GCP and Dataflow concepts
- Familiarity with BigQuery and Pub/Sub

## Related Labs
- GSP192: Dataflow: Qwik Start - Templates

## Notes
This guide provides step-by-step instructions for using pre-built Dataflow templates to quickly implement common data processing scenarios without writing custom code.
