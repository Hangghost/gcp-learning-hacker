# 美國聯邦選舉委員會 2016 年數據

## Description
這個連結指向美國聯邦選舉委員會 (FEC) 提供的 2016 年選舉數據。這些數據包含了候選人、捐款等相關資訊，常用於分析選舉趨勢和資金流向。

## URL
https://www.fec.gov/data/browse-data/?tab=bulk-data

## Category
documentation

- 研究人員
- 政治科學家
- 任何對選舉數據感興趣的人
