# Google Gen AI SDK Overview

## Description
The Google Gen AI SDK provides a unified interface to Google's generative AI API services, simplifying the integration of generative AI capabilities into applications.

## URL
https://cloud.google.com/vertex-ai/generative-ai/docs/sdks/overview

## Category
documentation

## Target Audience
- Developers integrating generative AI
- Application developers
- AI/ML engineers

## Prerequisites
- Basic Python programming
- GCP project with Vertex AI enabled
- Understanding of API concepts

## Related Labs
- GSP1209: Getting Started with Google Generative AI Using the Gen AI SDK

## Notes
Primary SDK for accessing Google's generative AI models including Gemini. Supports both synchronous and asynchronous operations.
