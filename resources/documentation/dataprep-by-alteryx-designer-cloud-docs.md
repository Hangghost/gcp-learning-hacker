# Dataprep by Alteryx Designer Cloud (Trifacta)

## Description
Trifacta (現在是 Alteryx Designer Cloud 的一部分) 是一個用於視覺化探索、清理和準備資料以進行分析的智慧資料服務。它提供無伺服器、可擴展的資料準備功能，無需部署或管理基礎設施。
