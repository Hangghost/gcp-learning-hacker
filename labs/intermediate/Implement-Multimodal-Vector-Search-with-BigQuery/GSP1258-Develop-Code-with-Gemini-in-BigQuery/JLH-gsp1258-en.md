# GSP1258 - Develop Code with Gemini in BigQuery

## Lab Overview
In this lab, you learn how to generate, explain, transform, and debug SQL code using Gemini in BigQuery. You will act as a data analyst learning to create complex SQL queries using natural language prompts and leverage Gemini's features to improve your code.

## Prerequisites
- Basic SQL knowledge
- Access to Google Cloud console
- Basic understanding of BigQuery concepts

## Learning Objectives
By the end of this lab, you will be able to:
- Generate a SQL query using a natural language prompt
- Use the code explanation feature of BigQuery
- Modify SQL code with the transform feature of BigQuery
- Prompt Gemini to review and debug SQL code in BigQuery
- Ask Gemini for suggestions to fix a SQL code issue

## Estimated Time
45 minutes

## Lab Steps

### Task 1: Review menu and order_item tables

#### Review the menu table schema
1. In the Google Cloud console, on the Navigation menu, click BigQuery
2. Click DONE on the Welcome dialog
3. In the Explorer panel, expand the `set at lab start` project
4. Expand the `coffee_on_wheels` dataset
5. Click the `menu` table to view the schema
6. Review the schema details

**Question: Which fields use FLOAT as datatype?**

#### Review the order_item table schema
1. Click the `order_item` table to view the schema
2. Review the schema details

**Question: Which fields use INTEGER as the data type?**

### Task 2: Generate a SQL query using a natural language prompt

#### Generate query showing top 3 and bottom 3 revenue menu IDs
1. Click + to create a new SQL Query tab
2. Click the SQL generation tool button
3. Enter prompt: "Show the menu IDs and total revenue from the order_item table with the top three highest and top three lowest by total revenue."
4. Click **Generate**
5. Click **INSERT** to add the query to the tab

#### Explain the generated query
1. Select the query
2. Click the Gemini button to the left of the query
3. Click **Explain this query**
4. Review Gemini's explanation
5. Click **RUN** to view results

**Reflection Questions:**
- Considering your data and use cases for BigQuery, how would you use the code generation feature?
- Also, how would you use the code explanation feature?

### Task 3: Transform a query

#### Generate query with menu names included
1. Create a new SQL query tab
2. Use the SQL generation tool
3. Enter prompt: "Join the menu table with the order item table, return the menu_id, the item_name, and show the top three highest items and bottom three lowest items by total_revenue."
4. Click **Generate** and **INSERT**
5. Click **RUN** to view results

#### Format total revenue to two decimal places
1. Select the query
2. Click the transform tool button
3. Enter prompt: "Format the total revenue column so that there are only two decimal places. Use the ROUND function to do so."
4. Click **GENERATE** and **INSERT**
5. Click **RUN** to view results

**Reflection Questions:**
- What is the total revenue generated by Clouds of Coffee Delight?
- Considering your data and use cases for BigQuery, how would you use the code generation feature?

### Task 4: Code review, debugging, and suggestions

#### Debug incorrect SQL query
1. Create a new SQL query tab
2. Enter the provided erroneous query
3. Click **RUN** to confirm the error
4. In Gemini chat window, ask for help and paste the query
5. Review Gemini's suggestions
6. Apply fixes and re-run

#### Format total revenue field to two decimal places
1. Request further code refinement in chat
2. Apply ROUND function fix
3. Test the final query

**Reflection Questions:**
- What is the name of the item with the 5th most revenue? Also, how much revenue did it generate?
- Considering your data and use cases, how would you use the code review and suggestion features to fix code you are struggling with?

## Verification
- Successfully generated and ran all SQL queries
- Results display correct menu items and revenue data
- Total revenue field correctly formatted to two decimal places

## Troubleshooting
- **Syntax errors**: Check generated SQL syntax, especially UNION operations
- **Dataset not found error**: Ensure correct dataset name `coffee_on_wheels` is specified
- **Explain not responding**: Re-select query and retry explanation
- **Transform failing**: Ensure prompt is clear and specific
