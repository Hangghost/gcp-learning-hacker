# GSP1154 - Vertex AI Studio 入門

## 實驗概述
Vertex AI 是一個全面的機器學習開發平台，提供預測性和生成式 AI 功能。它允許您訓練、評估和部署預測機器學習模型進行預測。此外，您還可以使用該平台發現、調整和提供生成式 AI 模型來產生內容。例如，保險公司不斷尋求改善索賠處理和風險評估的效率。Vertex AI Studio 提供了一種強大的方式來快速原型化此類挑戰的生成式 AI 解決方案。

Vertex AI Studio 讓您快速測試和自訂生成式 AI 模型，以便在您的應用程式中利用其功能。它提供了各種工具和資源，包括直觀的使用者介面 (UI)，讓您輕鬆開始使用生成式 AI，即使您沒有廣泛的機器學習背景。

此實驗將指導您完成 Vertex AI Studio，您將解鎖 Gemini 等尖端生成式 AI 模型的潛力。您將扮演協助保險公司原型化風險分析助理的角色。您將學習如何將提示想法轉化為可部署的應用程式，設計複雜的提示以實現特定的生成結果，並使用多模態功能來分析各種資料類型，包括影像，所有這些都直接在 Google Cloud 主控台中進行。不需要 API 或 Python SDK 來處理這些核心任務。

## 先決條件

開始此實驗前，您應熟悉：

- 基本 Python 程式設計概念
- Google Cloud Platform 基礎知識
- 生成式 AI 的基本概念

- **模型設定**：此區段允許您選取模型（包括第三方模型）、配置參數、使用工具（例如基礎）和設定進階選項。

- **提示**：此區段是您草擬提示的地方，可以利用多模態功能。

### 任務 2. 設計有效的提示

在任務 1 中，您原型化了初始提示。現在，您將深入探討精煉提示以從生成模型獲得更精確、控制和有用的輸出。這是提示工程的核心技能。您將繼續您的保險主題，試圖從索賠文件中提取特定資訊或改善總結品質。

### 零樣本提示

您將從創建新提示開始探索詳細的提示設計。

1. 確保您在主要的**Vertex AI Studio**區域。如果您從任務 1 檢視您的部署應用程式，請關閉該瀏覽器分頁以返回 Google Cloud 主控台。

2. 在左上角，選取**新增 > 聊天**。這將帶您到新的提示編輯器頁面。

3. 按一下**未命名提示**並將其重新命名為 `保險索賠資料提取`。

4. 熟悉此區段的情境：*保險理賠員經常收到關於新索賠的非結構化筆記或電子郵件，需要快速提取關鍵資訊片段以輸入到他們的索賠管理系統中。*

5. 在**系統指令**方塊中，輸入以下內容：

   ```
   您是專門解析和提取保險索賠通知中特定資料點的 AI 助理。

   您的目標是準確識別和列出關鍵資訊。

   以鍵: 值格式輸出提取的資訊，每個鍵在新行上。

   ```

   "嗨團隊，剛接到 Eleanor Vance 太太的電話，保單 #POL458892。她報告說廚房火災發生於 5 月 12 日下午 3 點左右。主要損壞似乎是烤箱和周圍櫥櫃。她提到廚房和用餐區也有煙霧損壞。她認為總損壞可能約 $7,500。她的聯絡是 555-0123。幸好沒有傷亡。"

   提取以下內容：

   - 保單編號

   - 索賠人姓名

   - 損失日期

   - 損失時間

   - 損失類型

   - 損壞簡要描述

   - 估計損失金額

   - 報告傷亡
   ```

7. 在**模型設定**區段：

   - 選取**`model_name`**模型。

   - 將**溫度**設定為`0.1`（用於更事實性、更少的創造性提取）。

   - 將**輸出權杖限制**設定為合理的數字，例如`1024`。

   - 確保**地區**為**全域**。

8. 按一下**提交**箭頭按鈕。檢閱輸出。這第一次嘗試沒有明確範例稱為**零樣本提示**。

### 試驗提示配置

現在，您將探索**模型設定**中的不同參數如何影響模型的回應。確保您的"保險索賠資料提取"提示與少樣本範例保持活躍。

**注意：**您的"保險索賠資料提取"提示專為準確性和結構設計。要看到**溫度**和**Top-P**等參數的效果，最好使用創造性提示。

首先，為這些試驗創建新的提示：

1. 在左上角，選取**新增 > 聊天**。

2. 將提示命名為**保險故事**。

3. 在提示文字方塊中，貼上下列：

   ```
   寫一個*第一段*簡短故事，關於一個房主剛使用未來派的 AI 保險應用程式來歸檔索賠。索賠是針對一個古怪且意外的事件。
   ```

現在，您將試驗模型設定。

### 試驗模型設定

1. 試驗**溫度**：

   - **解釋：**溫度控制隨機性。較低值（例如 0.0-0.2）使輸出更專注和確定性。較高值（例如 1.5-2）鼓勵更多樣化或創造性回應。

   - **試試看：**將**溫度**變更為`1.5`。按一下**提交**並注意任何變化。然後，將**溫度**改回`0.1`，使用相同的提示，並再次按一下**提交**。

2. 試驗**輸出權杖限制**：

   - **解釋：**這設定模型為其回應可以生成的最大權杖（單詞部分）數。

   - **試試看：**將**輸出權杖限制**設定為非常小的數字，例如`500`。使用相同的提示，按一下**提交**並觀察截斷的輸出。將其重設為最大長度（預設）`65535`。

3. 試驗**Top-P**：

   - **解釋：**Top-P（核心取樣）也控制隨機性。它僅考慮其累計機率超過 Top-P 值的最高機率權杖。值為`1.0`考慮所有權杖。降低 Top-P（例如到`0.8`）使輸出更專注，類似於降低溫度。

   - **試試看：**在溫度為`0.1`（或稍微更高，如`0.5`，以更好地觀察 Top-P 效果）的情況下，將**Top-P**設定為`0.8`。使用相同的提示並按一下**提交**。然後將**Top-P**設定為`1.0`，使用相同的提示並按一下**提交**，並觀察是否有細微差異。

4. 簡要檢閱**進階**模型設定面板中的其他設定：

   - **安全篩選設定：**預設為活躍，以幫助阻止有害內容。在此實驗中，您將使用預設設定。

   - **思考預算**：此參數指導模型在生成回應時使用的思考權杖數。較高的權杖計數通常允許更詳細的推理，這對於處理更複雜的任務有益。它預設為**自動**，但也可以設定為**關閉**或**手動**。當設定為手動時，模型在達到指定的權杖限制後停止分析；您可以為簡單任務設定較低限制，為更複雜任務設定較高限制。

   - **結構化輸出**：強制模型生成嚴格遵循預定義架構（例如 JSON）的回應。

   - **基礎：Google**：將模型連接到 Google 搜尋或地圖，啟用以即時、公用資訊回答。

   - **基礎：您的資料**：允許模型從您的資料來源（例如 Vertex AI 搜尋或 RAG 引擎）擷取資訊來回答情境特定問題。

按一下**檢查我的進度**來驗證目標。

在 Vertex AI Studio 中進行提示工程。

### 任務 3. 工程和管理提示

一旦您有工作提示，您通常會想要試驗對指令或模型配置的變更，以查看是否可以改善回應。Vertex AI Studio 中的"比較"功能專為此設計。在此區段，您將使用我們剛創建的提示。

1. 在左上角，選取**新增 > 聊天**。這將帶您到新的提示編輯器頁面。

2. 將新提示命名為**保險風險因素識別**。

3. 設定此簡單的基礎提示：

   - 在**系統指令**方塊中，輸入：

     ```
     您是保險風險分析助理。您的任務是從給定情境識別潛在風險因素。保持簡潔。
     ```

   - 在主要提示區域中，貼上下列：

     ```
     情境：

     "申請人 'The Fiery Grill' 是專精於木火爐披薩和明火燒烤的時尚餐廳。他們已安裝全新的、自訂的消防滅火系統用於烹飪區域，但尚未由第三方認證。餐廳計劃在週末晚上舉辦現場原聲音樂，並有一個小型、升高的舞台區域。他們還想要提供代客泊車。"

     基於此情境，列出承保員應考慮的三個主要風險因素。
     ```

   - 在右側的**配置**區段：

     - 選取**`model_name`**模型。

     - 將**溫度**設定為`0.2`。

     - 確保**地區**為**全域**。

4. 按一下**提交**箭頭按鈕。檢閱模型的初始回應。

5. 如果您的提示尚未自動儲存，按一下**儲存**按鈕。

6. 現在，在您的**保險風險因素識別**提示及其回應顯示的情況下，按一下提示名稱旁右上角的三點，然後選取**比較**。

### 比較：修改系統指令

您現在將看到變更指令如何影響您的提示回應。

1. 在**系統指令**方塊中（對於右側的提示），編輯現有的系統指令以進行更新。將其更新為以下：

   ```
   您是專家保險風險分析助理。您的任務是從給定情境識別潛在風險因素。對於每個風險因素，還簡要建議潛在緩解策略或承保員的問題。保持清晰和結構化。
   ```

1. 保持其他模型設定相同，並在頁面底部方塊中提交以下提示：

   ```
   情境：

   "申請人 'The Fiery Grill' 是專精於木火爐披薩和明火燒烤的時尚餐廳。他們已安裝全新的、自訂的消防滅火系統用於烹飪區域，但尚未由第三方認證。餐廳計劃在週末晚上舉辦現場原聲音樂，並有一個小型、升高的舞台區域。他們還想要提供代客泊車。"

   基於此情境，列出承保員應考慮的三個主要風險因素。
   ```

1. 等待兩個提示生成回應。並排檢閱兩個回應。由於修改的指令，第二個提示現在是否包含緩解策略或問題？隨意進一步修改系統指令以查看它如何指導模型回應。

### 比較：不同的溫度設定

現在，您將使用比較窗格來測試不同的溫度。

1. 對於右側的提示，將**系統指令**恢復為與左側相同的。

   ```
   您是保險風險分析助理。您的任務是從給定情境識別潛在風險因素。保持簡潔。
   ```

1. 對於**右側**的提示，開啟**模型設定**窗格，並將**溫度**變更為`2.0`。確保模型仍為**`model_name`**。

2. 在頁面底部方塊中提交以下提示：

   ```
   情境：

   "申請人 'The Fiery Grill' 是專精於木火爐披薩和明火燒烤的時尚餐廳。他們已安裝全新的、自訂的消防滅火系統用於烹飪區域，但尚未由第三方認證。餐廳計劃在週末晚上舉辦現場原聲音樂，並有一個小型、升高的舞台區域。他們還想要提供代客泊車。"

   基於此情境，列出承保員應考慮的三個主要風險因素。
   ```

1. 觀察回應中的差異。較高的溫度（`2.0`）是否使第二個提示中的風險因素列表不如`0.2`溫度輸出專注、更多推測性或顯著不同？**注意：**將溫度設定這麼高很可能會導致不連貫或不相關的輸出，但它示範了參數的極端效果。

### 比較：不同的模型和配置

現在您將嘗試比較您的基礎模型與不同的模型和設定，以觀察推理或輸出風格的差異。

1. 對於**右側**的提示，開啟**模型設定**窗格並進行以下變更：

   - 將**模型**變更為**`model_name`**

   - 將**溫度**設定為`0.2`

2. 對於**左側**的提示，開啟**模型設定**窗格並進行以下變更：

   - 確保**模型**設定為**`model_name`**

   - 將**溫度**設定為`0.2`

   - 將思考預算**關閉**。

3. 在頁面底部方塊中提交以下提示。此提示故意更複雜以顯示模型在推理能力方面的差異。

   ```
   情境：

   "申請人 'The Fiery Grill' 是專精於木火爐烤箱和明火燒烤的時尚餐廳。他們有全新的、自訂的消防滅火系統，但尚未由第三方認證。餐廳將舉辦現場原聲音樂在一個小型、升高的舞台上。他們還想要由他們自己的員工管理的代客泊車。申請人沒有先前的業務歷史。"

   承保指南：

   優先順序階層：責任風險歸類為：

   - 類別 A（關鍵）：火災、結構故障、安全系統故障。

   - 類別 B（標準）：一般場所責任（例如，滑倒）。

   - 類別 C（利基）：自動/車輛責任。

   複合因素：一個"複合風險"（使另一個風險更糟的條件）必須提升到最高優先順序。

   無經驗：缺乏先前的業務歷史是一般負面因素，但本身不創造主要風險。

   自動責任：類別 C 風險（代客泊車）只有在申請人使用未經篩選的、第三方承包商時才被視為主要風險。

   任務：

   基於情境和承保指南，識別承保員應考慮的單一、#1 最高優先順序風險。然後，寫一個 2 句理由解釋為什麼它是 #1 風險，引用適用指南中的特定準則。`
   ```

1. 檢閱回應。比較**`model_name`**（左窗格）與**`model_name`**（右窗格）的輸出。

您應該看到明確差異。`model_name`模型（左）很可能提供快速但一般的答案，例如識別整體危害（"火災"）。`model_name`模型（右）應該提供更精確和可操作的答案，透過隔離特定風險（"未經認證的消防滅火系統"）。注意 Pro 模型的理由如何更詳細，可能引用多個指南來顯示其更深入的推理。

按一下**檢查我的進度**來驗證目標。

### 任務 4. 使用 Gemini 的多模態提示

在此任務中，您將使用 Vertex AI Studio 中的主要提示介面與 Gemini 模型來分析影像並從中提取資訊。這示範了如何設計用於各種分析任務的提示，例如描述、文字提取和基於視覺內容的問題解答。

1. 導覽回到**Vertex AI Studio**頁面。

2. 在左上角，按一下**新增 > 聊天**。

3. 將提示命名為**時間表影像分析**。

4. 在提示方塊左下角，按一下**+**按鈕，然後選取**從 Cloud Storage 匯入**。

5. 在功能表中，選取預建的 Cloud Storage 貯體，然後是`timetable.png`檔案。

6. 在右側的**模型設定**面板中：

   - 確保選取了**`model_name`**模型。

   - 確保**地區**為**全域**。

7. 現在，您可以要求模型對影像執行幾項任務。在提示輸入欄位中插入的影像下方，貼上下列提示：

   ```
   1. 為此影像提供簡潔標題（少於 5 個字）。

   2. 用一兩句話描述影像。

   3. 從影像中提取所有可見文字。以清晰格式化的列表呈現班表，具有"時間"和"城市"的欄位。
   ```

1. **提交**提示並檢閱模型的回應。

2. 接下來，您可以問一個需要基於提取資訊的推理問題。提交下列提示：

   ```
   基於影像中顯示的班表，列出的航班中有百分之多少在上午 11:30 前起飛？如果可能，顯示您的計算。

1. 按一下**提交**按鈕並檢查回應。

2. 簡要觀察溫度的效果。在**模型設定**面板中：

   - 將**溫度**調整為`0.8`。

   - 使用相同的提示重新提交*完全相同的*（"基於班表...百分比..."）。

   - 注意解釋的風格、信心或細節是否變化。

   - 觀察後，將**溫度**設定回較低的值，如`0.2`，以獲得更可預測的回應。

**注意：**溫度控制隨機性。較低值（例如 0.0-0.2）對於事實回應良好，而較高值（例如 0.7+）可能導致較少適合精確資料提取或分析的更多樣化輸出。

### 任務 5. 在 Vertex AI Studio 中生成媒體

除了文字，Vertex AI Studio 提供強大的工具來直接從文字提示或透過精煉現有媒體生成各種媒體類型。在此任務中，您將探索生成影像和語音。

### 使用 Imagen 生成影像

您將從生成影像開始。

1. 在**Vertex AI Studio**頁面的左上角，按一下**新增 > 影像**。

1. 在底部的文字提示區域中，輸入描述性提示：

   ```
   一個特寫、寫實影像，顯示一隻單獨的蜜蜂在收集粉紅色薰衣草花上的花粉，背景是柔和模糊的花園。
   ```

2. 在右側的**設定**面板中：

   - 確保**模型**設定為`Imagen 4`（或最新可用的 Imagen 模型）。

   - 對於**長寬比**，選取`1:1`。

   - 將**結果數量**設定為此第一次生成`4`。

   - 檢閱**安全**設定（例如，人員生成、安全篩選閾值）並將其保留為預設或根據此非人員專注提示進行調整。

3. 按一下**提交**按鈕提交您的提示。

4. 幾分鐘後，您的生成影像將出現在主要區域。

5. 按一下其中一個生成影像縮圖以開啟詳細檢視。

1. 在右側的**影像詳細資料**窗格中：

   - 觀察可用的**AI 動作**，例如`Inpaint`（使用遮罩添加/移除元素）、`Outpaint`（延伸影像）和`Export image`（可能提供升級）。

   - 注意是否顯示**SynthID 偵測**為綠色勾選。

   - （可選）：選取其中一個選項`Inpaint`或`Outpaint`並玩玩 Imagen 的功能。

### SynthID 是什麼？

SynthID 是 Google DeepMind 開發的一項技術，可將數位浮水印直接嵌入到 AI 生成影像的像素中。此浮水印設計為人類眼睛無法察覺，但可由演算法偵測。其目的是透過促進透明度和負責任的 AI 實踐來幫助識別影像為 AI 生成，即使影像稍後被修改（例如，壓縮、過濾）。

按一下**檢查我的進度**來驗證目標。

探索 Vertex AI Media Studio。

### 使用 Chirp 生成語音（可選）

如果您想探索 AI 生成語音：

1. 在遠左的垂直工具列中，按一下**音訊圖示**（看起來像麥克風）以切換到語音生成工具。這將開啟 Chirp 介面。

2. 您可能會被提示啟用**Cloud Text-to-Speech API**，如果它尚未為您的專案啟動。如果是，按一下**啟用**並等待 API 啟用（這可能需要一點時間）。

3. 一旦介面準備就緒，在底部的文字提示區域中，輸入您要合成化的文字。例如：

   ```
   歡迎來到 Google Cloud 上的生成式 AI 世界
   ```

1. 在右側的**設定**面板中：

   - 選取**模型**（例如，`Chirp 3. HD Voices`）。

   - 選擇您的所需**語言**（例如，`English (US)`）。

   - 從下拉列表中選取**聲音**。您可以嘗試幾個不同的聲音來聽它們的特點。

   - 探索任何可用的**進階選項**並根據需要調整。

2. 按一下**提交**按鈕。

3. 處理後，您應該能夠直接在介面中播放生成音訊。
