### Step 3: Create Non-Streaming Chat Responses

This step demonstrates how to create a simple chat application that sends prompts and receives non-streaming responses.

**Instructions:**

1. Create a new Python file and paste the following code:

```python
from google import genai
from google.genai.types import HttpOptions, ModelContent, Part, UserContent

import logging
from google.cloud import logging as gcp_logging

# Initialize GCP logging (for Qwiklab's internal use, do not edit/remove)
gcp_logging_client = gcp_logging.Client()
gcp_logging_client.setup_logging()

# Initialize Gemini client
client = genai.Client(
    vertexai=True,
    project="your-project-id",  # Replace with your project ID
    location="us-central1",      # Replace with your region
    http_options=HttpOptions(api_version="v1")
)

# Create chat conversation
chat = client.chats.create(
    model="gemini-2.0-flash-001",
    history=[
        UserContent(parts=[Part(text="Hello")]),
        ModelContent(
            parts=[Part(text="Great to meet you. What would you like to know?")],
        ),
    ],
)

# Send message and get response
response = chat.send_message("What are all the colors in a rainbow?")
print(response.text)

response = chat.send_message("Why does it appear when it rains?")
print(response.text)
```

2. Save the file as `SendChatwithoutStream.py`
3. Run the code to see the output

**Expected Result:**
- Code executes successfully and displays information about rainbow colors

### Step 4: Create Streaming Chat Responses

Now let's explore how to create streaming chat responses that display responses in real-time as they are generated.

**Instructions:**

1. Create a new Python file and paste the following code:

```python
from google import genai
from google.genai.types import HttpOptions

import logging
from google.cloud import logging as gcp_logging

# Initialize GCP logging (for Qwiklab's internal use, do not edit/remove)
gcp_logging_client = gcp_logging.Client()
gcp_logging_client.setup_logging()

# Initialize Gemini client
client = genai.Client(
    vertexai=True,
    project="your-project-id",  # Replace with your project ID
    location="us-central1",      # Replace with your region
    http_options=HttpOptions(api_version="v1")
)

# Create chat conversation
chat = client.chats.create(model="gemini-2.0-flash-001")
response_text = ""

# Send message with streaming and display response in real-time
for chunk in chat.send_message_stream("What are all the colors in a rainbow?"):
    print(chunk.text, end="")
    response_text += chunk.text
```

2. Save the file as `SendChatwithStream.py`
3. Run the code to see the streaming output

**Expected Result:**
- Code executes successfully and displays response in streaming fashion

## Troubleshooting

Common issues and their solutions:

- **Authentication errors**:

  - Check that the project has sufficient permissions

- **Import errors**:
  - Ensure packages are installed with correct versions
  - Check Python environment setup

- **Network connectivity issues**:
